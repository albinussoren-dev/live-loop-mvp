# LoopLive MVP

A Next.js dashboard prototype for a 50-user YouTube live-loop SaaS.

## MVP
- Responsive streaming dashboard
- YouTube connection placeholder
- Authorized video library placeholder
- Start/stop stream interaction
- Live status and stats
- Responsive dark UI

## Production roadmap
- Google/YouTube OAuth and encrypted token storage
- YouTube API integration
- FastAPI + PostgreSQL
- Redis job queue
- Authorized media pipeline with FFmpeg
- YouTube Live API + RTMP broadcast lifecycle
- Scheduling, auto-restart, logs, billing and admin

Use only content and APIs you are authorized to access and comply with YouTube policies.
